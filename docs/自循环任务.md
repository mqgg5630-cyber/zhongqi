# 自循环任务 —— docx / pptx 生成 ⇄ 本机核验 ⇄ 状态回推

这个仓库现在有一条**闭环流水线**：

```
   Arena 沙箱（agent 侧）                              你的 Windows 本机
   ─────────────────────                              ─────────────────
 1  python code/build_deliverables.py
    重生成 docx / pptx（复用仓库既有生成脚本）
    逐个断言：页数 / 段落数 / 封面信息 / 术语
    与 HEAD 比内容指纹（一致就还原原字节，不做无谓的二进制 churn）
    跑闸门 code/check_all.sh
    写 results/status/agent_manifest.json（含每个文件 sha256）
    编译 results/status/success_criteria.json
              │
 2  agent-handsfree.sh --sync ... --request ...
    = agent-sync.sh（守卫 + 闸门 + 回执 + commit + push）
    + agent-check.sh --request（handshake: round+1,
      arena_state=awaiting_check, local_state=pending）
              │                                    ┌── 值守每 2 分钟轮询（watch.ps1）
              └────── git push 到工作分支 ─────────►│   auto_pull：自动 .\sync.ps1
                                                    │   看到 awaiting_check + pending：
                                                    │     跑 code/local_check.ps1
                                                    │       ├ 闸门（.ps1 ASCII / 分支守卫 / 脚本一致）
                                                    │       ├ 免点击推送自检（auth.ps1 -Verify）
                                                    │       ├ 值守零窗口自检（计划任务形态）
                                                    │       ├ code/check_deliverables.ps1
                                                    │       │   在场 + 体积 + **sha256 与清单一致**
                                                    │       │   + OOXML 包结构 + 页数/段落数复核
                                                    │       └ success_criteria.json 逐条核对
                                                    │     写 results/status/check_rN_<stamp>.txt
                                                    │     handshake.local_state = passed / failed
              ┌────── git push 回同一分支 ◄─────────┤     push.ps1 -NoPrompt 静默推回
              ▼
 3  agent-wait.sh 轮询远端 handshake（结论一到就返回，不死等）
    agent-criteria.sh 再核一遍 success_criteria.json
      exit 0 → agent-check.sh --accept（arena_state=accepted）→ **闭环完成，停**
      exit 2 → 打印本机失败详情 → 修 → 下一轮（round+1）
      exit 3 → 本机值守不在线 → **停，不假装成功**，重贴本机那段 PowerShell
```

一句话：**产物走 git 到你机器，结论走 git 回来**，中间没有任何"沙箱里的假本机"。

## 二、本机一次性打通（Windows PowerShell）

**"与本地打通"= 你机器上存在这个分支的克隆 + 一个在跑的 `git-sync-watch-*` 计划任务。**
沙箱里建 `local/inbox/`、写 python 桥、只在沙箱 commit 都不算。

### 路 A（推荐）：复用你已有的克隆 `E:\0zhongqi\zhongqi`

```powershell
cd E:\0zhongqi\zhongqi
git fetch origin
git checkout arena/01a0a95e-zhongqi
git pull --ff-only origin arena/01a0a95e-zhongqi
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
.\bootstrap.ps1 -Auto      # 身份 + 切分支 + 免点击推送 + 注册值守（零窗口）
.\doctor.ps1               # 体检
.\watch.ps1 -Status        # 值守活着吗
```

### 路 B：新开一个文件夹（不动旧克隆）

```powershell
cd E:\0github\git-sync
git clone -b arena/01a0a95e-zhongqi https://github.com/mqgg5630-cyber/zhongqi.git zhongqi-01a0a95e
cd zhongqi-01a0a95e
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
.\bootstrap.ps1 -Auto
.\doctor.ps1
.\watch.ps1 -Status
```

**成功标志**（`doctor.ps1` 末尾 + `watch.ps1 -Status`）：

- `branch` = `arena/01a0a95e-zhongqi`，`ahead/behind = 0/0`
- `watcher / heartbeat / auth` 三行都是好消息，`hands-free master=True`
- `loop process: pid ... (running)`，`last_push: ok`

> `bootstrap.ps1 -Auto` 会**暂停**其他会话的 `git-sync-watch-*` 任务（任务保留、循环停掉）。
> 要回旧会话：`cd <旧克隆> ; .\watch.ps1 -Focus`；全部恢复：`.\watch.ps1 -RestoreParked`。
> 不想动别人：`.\watch.ps1 -Register -KeepOthers`。

打通之后**你不用再敲任何命令**：值守每 2 分钟自动拉我的更新、自动静默推你的改动、
我请求核验时自动跑检查并把结论推回来。想把成品复制到仓库外：`.\download.ps1 -Set final`。

## 三、"结果没问题"是怎么定义的（三层，都可机读）

| 层 | 在哪跑 | 判什么 | 失败长什么样 |
|---|---|---|---|
| ① 生成与断言 | agent 沙箱 | `code/deliverables.tsv` 的 `expect`：H 版 `slides=20`、中间版 `slides=12`、docx `paras>=150`、封面 `has=文绍华/2024110316/生命科学学院/申亮`、术语 `has=乙酰胆碱酯酶/纸片扩散法/三模型共识预测/宏蛋白组二次去重`、体积下限 | `build_deliverables.py` exit 2，清单 `verdict:"fail"` |
| ② 格式与口径闸门 | 两侧都跑 | `code/check_all.sh`：模板格式零改动（`verify_docx.py`）、docx 与全部 PPT 口径一致（`check_consistency.py`）、PPT 版式不溢出（`check_ppt.py`）、`.ps1` 全 ASCII + 引号括号平衡、根目录脚本与 skill 逐字节一致 | 闸门 exit 1 → **不允许 push** |
| ③ 落地完整性 | 你的本机 | `code/check_deliverables.ps1`：清单里每个文件在场、体积达标、**sha256 与我生成的完全一致**、zip 是合法 OOXML 包（`word/document.xml` / `ppt/presentation.xml`）、页数与段落数在本机独立复核一致；外加 `auth.ps1 -Verify`（免点击推送）与值守形态自检 | 本机把 `local_state=failed` 推回分支，`results/status/check_rN_*.txt` 里逐行写着哪个文件哪一条不过 |


### agent 侧（我在沙箱里跑）

```bash

bash code/loop_deliverables.sh --agent-only           # 本机还没连通时：只跑 agent 侧并推送
bash code/loop_deliverables.sh --status               # 看握手状态 + 最近一次本机结论
bash code/loop_deliverables.sh --max-rounds 3 --interval 20

bash skills/git-sync/scripts/agent-handsfree.sh \
     --sync "feat(loop): ..." --request "verify: ..." --timeout auto     # 单轮闭环
bash skills/git-sync/scripts/agent-check.sh --read                        # 只读结论
bash skills/git-sync/scripts/agent-criteria.sh                            # 只核验收标准
bash skills/git-sync/scripts/agent-sync.sh --status                       # 只看同步状态
```

退出码（`loop_deliverables.sh` 与 `agent-handsfree.sh` 一致）：

| 码 | 含义 | 下一步 |
|---|---|---|
| 0 | 本机 passed + 验收标准过 + 已 accept | 收工 |
| 1 | agent 侧生成/闸门没过 | 先修生成，别把坏产物推给本机 |
| 2 | 本机判 failed（或轮次用尽） | 读 `results/status/check_rN_*.txt` → 修 → 再跑一次脚本（round+1） |
| 3 | 本机值守不在线 / 超时 | **停**，重贴第二节那段 PowerShell；不许改口说"沙箱已打通" |

## 六、卡住了怎么办

| 症状 | 原因 | 处理 |
|---|---|---|
| `agent-handsfree` 一直 exit 3 | 本机没有这个分支的克隆，或值守没注册 | 跑第二节；`.\watch.ps1 -Status` 看到 heartbeat 才算通 |
| 本机判 failed：`FAIL sha256` | 本机那份是旧的 / 被截断 | `.\sync.ps1`（或等 auto_pull），再让我重开一轮 |
| 本机判 failed：`accept 2a` | 推送还要点确认 | `.\auth.ps1 -Setup -Verify` |
| 本机判 failed：`accept 2b` | 值守在按轮起新进程（会闪窗） | `.\watch.ps1 -Unregister ; .\watch.ps1 -Register` |
| 闸门红：`non-ASCII bytes in *.ps1` | 有人在 `.ps1` 里写了中文 | 中文挪到 `.md` / `.json`；`python code/check_ps1.py` 复查 |
| 闸门红：`*.ps1 differs from skills/git-sync/scripts` | 改了根目录副本没同步 | `cp skills/git-sync/scripts/<x>.ps1 <x>.ps1` |
| 升级了 skill 但值守行为没变 | 计划任务里写死的是旧启动命令 | `.\watch.ps1 -Unregister ; .\watch.ps1 -Register` |
| 沙箱 `.git` 被重置回基线提交 | Arena 沙箱偶发 | `bash skills/git-sync/scripts/agent-recover.sh`（保住工作区、恢复历史） |

**红线**（踩了就等于没打通）：不推 `main`/`master`；不 `--force`；不 `git init` 新仓库再推同一分支；
不在沙箱里造假本机（`local/inbox`、python 桥、自己写一套 docx skill 冒充"装了 01a0a821 的 skills"）；
本机没回结论就不说"已返回本机"。
