## 三、答辩预判问题与应答要点

1. **为什么用三个模型而不是自己训练一个模型（开题里写的 DeepMetaAMP）？**
   开题时计划自建模型；实施阶段评估后改为采用 Attention、LSTM、BERT 三个已有模型协同预测：一是三个模型的训练数据与评测体系成熟、结果可比；二是三模型一致性判定可以显著降低单一模型的偏倚；三是把时间集中投入到数据资源构建与差异／去重分析这些更有增量的环节。研究问题与结论形态没有改变。

2. **"宏蛋白组去重"具体解决什么问题？**
   解决"序列上可能存在、但实际并不表达"的假阳性：先在序列层面去掉冗余，再用宏蛋白组的表达证据过滤，只保留能检出的肽；这样后续的差异分析与实验验证都建立在更可能真实存在的候选肽上。

3. **"健康人特有 / 阶段特有"是怎么定义的？**
   先对每个分组分别确定其检出的抗菌肽集合，再比较组内共有与组间特有：只在健康组出现的即为健康人特有，只在某一疾病阶段出现的即为该阶段特有。具体判定阈值与统计标准属于细节，可按需展开。

4. **机制关联为什么参照 AChE–Aβ 那篇文献？**
   该研究用分子对接与分子动力学模拟证明 Aβ 肽可稳定结合乙酰胆碱酯酶的外周阴离子位点，并给出了主要驻留区段与额外接触位点。这为"抗菌肽是否也能与 Aβ、AChE 相互作用、从而影响聚集与成核"提供了可复用的模拟思路，因此本课题采用同类方法考察候选抗菌肽。

5. **抑菌实验为什么做得这么简单？**
   本次目的是对候选肽做最小可行性验证，而不是完整药理评价：先用纸片扩散法看有无抑菌圈，再用微量肉汤稀释法给出最低抑菌浓度，配合阳性／阴性对照即可回答"有没有活性"这一问题；更系统的评价（如溶血性、稳定性）留待后续工作。

6. **进度是否偏慢？**
   研究主体已完成（数据处理、短肽库、三模型预测、分阶段差异分析、宏蛋白组去重与特异肽筛选），当前集中在机制关联与抑菌实验两件事上，论文撰写同步推进，整体与开题安排一致。

7. **中期报告里为什么没有具体数值？**
   按导师意见，中期检查侧重研究思路与工作完成程度；具体数值与图表将在完成后统一呈现在学位论文与投稿论文中。

## 四、制作与修改说明

- 生成脚本（可重跑）：
  - `code/make_figures2.py` → 本版 7 张流程示意图（figA—figG）
  - `code/make_ppt2.py` → 本版 PPT 成稿
  - `code/check_ppt.py` / `code/preview_ppt.py` → 版式检查与逐页预览
- 改文字：直接改 `code/make_ppt2.py` 对应页，或直接在 PowerPoint 中编辑。
- 字体：中文**微软雅黑**、西文 Arial，并在 XML 中显式写入东亚字体，避免他人电脑上字体回退。
- 字号：正文与图内文字均 ≥15 pt；两张图的图内最小字号为 14.5 pt，按图在页面上的实际缩放投影后分别为 15.8 pt 与 16.1 pt（`make_figures2.py` 会核算并打印这一数值）。
- 第 7 页两张示意图标注了"流程示意"：它们是分析思路的示意，不是本课题的真实数据，答辩时如被问到可直接说明。
