## 机制说明相关（2026-09 新增）

| 概念 | 统一写法 | 说明 |
|---|---|---|
| 抗菌保护假说 | 抗菌保护假说（antimicrobial protection hypothesis） | Aβ 作为先天免疫效应分子；首次出现写全称 |
| 抗菌肽（宿主来源） | 宿主来源抗菌肽 | β-防御素-1、CAP37、LL-37 等 |
| 抗菌肽（微生物来源） | 微生物源抗菌肽 | 本课题对象：肠道微生物基因组 sORF 编码 |
| AChE 成核位点 | 外周阴离子位点（peripheral anionic site, PAS） | 首次出现写全称＋缩写 |
| Aβ 在 AChE 上的停留区 | AChE 344–361 区段 | 引用 Atanasova 等 2020 的模拟结果 |
| 三个介入假设 | H1 竞争 PAS / H2 结合 Aβ / H3 膜水平作用 | 机制部分只用这三个编号，不另起说法 |
| 表述边界 | “线索发现”“假设提出”“计算预测” | 不说“证明”“导致”“因果” || 交叉成核 | 交叉成核（cross-seeding） | 抗菌肽与淀粉样肽互为模板；只用这一说法，不写“共聚集” |
| 分子动力学 | 分子动力学模拟（MD） | 首次出现写全称 + 缩写；具体时长写“1 μs（1000 ns）” |
| 感染负担 | 人群归因分数（PAF） | 引用 [16] 的估计值时标明是人群归因分数 |
