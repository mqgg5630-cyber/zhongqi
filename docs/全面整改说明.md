## 4. 逐问回答（对应用户括号中的追问）

### 抗菌活性的预测这部分是不是没说呢
**已补充**：原PPT第6页只讲三模型共识，未展开可行性文献。现机制补充页第20页（M4右侧）用3条文献说明：

并说明本课题口径：三模型共识→宏蛋白组二次去重→抑菌实验验证（纸片扩散初筛+MIC，设阳性LL-37/阴性溶剂对照）。

### 正常人AD哪个抗菌肽更多
**方向AD侧更高**，但分层：
- **宿主来源**：hBD-1在AD海马/脉络丛上调[7]；hBD-2/HNP1-3在血清/CSF升高，DEFB4拷贝数更高[8]；CAP37上调[9]；LL-37上调[10,11]；总抗菌活性AD脑匀浆>对照且可被抗Aβ抗体清除[1]。
- **微生物源**：尚无一致结论，本课题按NC/SCS/SCD/MCI/AD五阶段比较，以本项目数据为准。

### 为什么多 炎症的关系
**正反馈环**：
1. 上游：菌群失衡（促炎菌Escherichia/Shigella、Proteobacteria↑，产丁酸菌Eubacterium、Faecalibacterium↓）+肠屏障↑→LPS持续入血，血浆LPS约3倍[13,14][19-21]
2. 中游：LPS与Aβ均为TLR4/CD14激动剂，经MyD88→NF-κB释放IL-1β/TNF-α/IL-6，上调APP加工和Aβ/抗菌肽表达[13,18]
3. 下游：Aβ/抗菌肽聚集→激活小胶质（NLRP3炎症小体、CLIC1通道致ROS）→更多炎症介质和Aβ/抗菌肽[10,11]
4. 循环加强：AChE-PAS促纤维化[27-32]，形成自我加强环。

### 抗菌肽是促进AD发生还是抑制感染
**双刃剑**，两者都是：
- **抑制感染（生理）**：Aβ对8种微生物活性≥LL-37，反向/打乱无活性，寡聚化必需且耐蛋白酶[1]；小鼠/线虫Aβ表达提高抗感染加倍存活[2]；Aβ抑制HSV-1复制入侵，斑块包裹病毒保护免于脑炎[4,5]；机制：可溶寡聚体经肝素结合域结合微生物碳水化合物，抑制黏附，原纤维凝集包裹[2-4]。
- **促进AD（病理）**：聚集层面：AChE-PAS成核，抗菌肽共组装改变成核与纤维形态，LL-37结合Aβ抑制长纤维但稳定更毒寡聚体[10-12][27-32]；炎症层面：LL-37经CLIC1致小胶质过度活化、神经炎症、兴奋毒性，动物模型致Aβ↑、NFT↑、脑萎缩[11]。

### AD与感染的关联
**多病原证据链**：
- HSV-1：90%斑块核心检出HSV-1 DNA，感染上调β/γ分泌酶致Aβ和tau病理[36]；HHV-6A/7升高[6]；抗菌保护假说解释[3]
- P. gingivalis：AD脑检出细菌及gingipains，Dominy 2019小分子抑制剂降低病理[15]；LPS与斑块共定位[13]；血浆LPS 3倍
- 肠道：菌群失衡→屏障↑→LPS入血→神经炎症，果蝇/小鼠模型证实[37,38]
