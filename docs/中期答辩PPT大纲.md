# 中期答辩 PPT 大纲

> 建议 12–16 页，讲 8–10 分钟。老师只听三件事：**做了什么、做到哪了、还要做什么**。
> 每页标题写"结论"，不要写"某某分析"这种话题式标题。

| 页 | 标题（结论式） | 内容要点 | 配图 |
|---|---|---|---|
| 1 | 封面 | 课题名称、姓名、学号、导师、日期 | 校徽 |
| 2 | 目录 | 背景与目标 / 已完成工作 / 阶段性成果 / 存在问题 / 下一步计划 | — |
| 3 | 研究背景：XX 问题尚未解决 | 3 条现状痛点，每条一行，配 1 篇文献 | 简洁示意图 |
| 4 | 研究目标：做出 XX，达到 XX 指标 | 目标拆成 3 条可检验的子目标 | 目标清单表 |
| 5 | 技术路线：数据 → 方法 → 验证 三步走 | 整体流程图，高亮"已完成"部分（用颜色区分） | **技术路线图（重点）** |
| 6 | 已完成 1：数据/素材已就绪 | 数据来源、规模、预处理前后对比 | 数据统计表 |
| 7 | 已完成 2：【待填核心工作一】 | 方法说明 + 关键公式（≤2 个） | 方法结构图 |
| 8 | 已完成 3：【待填核心工作二】 | 同上 | 对比曲线/柱状图 |
| 9 | 实验/验证结果：指标从 A 提升到 B | 主结果表 + 消融或对比 | 结果表 + 图 |
| 10 | 阶段成果清单 | 代码仓库、数据、论文/专利、获奖 | 清单 |
| 11 | 进度对照：已完成 XX%，与计划一致 | 甘特图或进度对照表 | **甘特图（重点）** |
| 12 | 存在的问题与解决思路 | 2–3 个问题 + 对应办法 | 表格 |
| 13 | 下一步计划与时间节点 | 剩余任务的甘特图 + 交付物 | 甘特图 |
| 14 | 致谢 / 请老师批评指正 | 联系方式 | — |

## 答辩现场容易被问到的问题（提前准备答案）

1. 你开题时说的 XX，为什么现在改成了 YY？（准备一句"依据实验结果的合理调整"）
2. 你的方法相比 baseline 到底好在哪，是参数量还是数据量的原因？
3. 进度是不是偏慢？剩余 XX 个月能做完吗？（用第 13 页的甘特图回答）
4. 你这个结果能否复现？跑一次要多久？
5. 创新点是什么，一条就够。
6. 下一步如果方法不work，有没有备选方案？

## 制作要求

- 每页字数 ≤ 60 字，正文最小字号 ≥ 20pt，别念稿。
- 图要清晰：从 `results/figures/` 导出 PNG（≥ 150 dpi），不要截屏贴图。
- 全部页面风格统一（同一套配色、同一字体），避免从不同模板拼贴。
- 文件名建议：`sources/中期答辩.pptx`，导出 PDF 备份以防现场格式错乱。
