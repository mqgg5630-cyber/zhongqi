# 机制解释要点（速查卡）

> 面向答辩被追问的场景。完整版见 `deliverable/抗菌肽与AD关联机制说明.docx`；

## 一句话

AD 患者肠道菌群失衡、肠屏障通透性增加 → 病原体与内毒素长期刺激宿主 → 抗菌肽与 Aβ 作为先天免疫效应分子被持续诱导 → 抗菌肽一方面抑制感染，另一方面与 Aβ 聚集、神经炎症相互促进 → 形成正反馈环。

## 机制落点（AChE–Aβ，Atanasova 2020 [15]）

- Aβ 对接进 AChE 的**外周阴离子位点（PAS）**后，复合物在 **1 μs（1000 ns）** 模拟中保持稳定；
- 除 PAS 外另有多处接触；Aβ 在 AChE 表面的主要停留区为 **344–361 区段**；
- 该区段紧邻 PAS，但**不受双位点抑制剂的空间位阻**——意味着存在第二条可利用的界面；
- 与 AChE 经 PAS 促进 Aβ 由 α-螺旋向 β-折叠转变、加速纤维生成的经典结论 [14] 相互衔接。

## 由机制推出的三个可检验假设

| 编号 | 假设 | 验证方式 |
|---|---|---|
| H1 | 竞争 PAS，减少 AChE 诱导的成核 | 对接 + MD 比较结合自由能；AChE 酶活实验 |
| H2 | 直接结合 Aβ，改变聚集路径与纤维形态 | ThT 动力学、电镜/AFM、MD 界面残基 |
| H3 | 膜水平作用，影响小胶质识别与炎症信号 | 脂膜模型 MD + 细胞炎症因子检测 |

## 口径纪律

- 用“线索发现 / 假设提出 / 计算预测”，不用“证明 / 导致 / 因果”；
- 数量差异一定说清是**哪一层**（宿主 vs 微生物源、局部 vs 系统、总体活性 vs 具体肽、哪个阶段）；
- “AD 侧更多”是文献支持的预期方向，微生物源抗菌肽的结论以本项目数据为准。
