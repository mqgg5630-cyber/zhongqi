# 机制解释要点（全面版·速查卡）

> 面向答辩被追问的场景。完整版见 `deliverable/抗菌肽与AD关联机制说明.docx`（已扩展至38篇文献，覆盖8个核心问题）；

## 一句话

肠道菌群失衡与肠屏障通透性↑ → LPS、P. gingivalis、HSV-1等长期刺激 → 抗菌肽与Aβ作为先天免疫效应分子被持续诱导 → 双刃剑：抑制感染（生理）vs 经AChE-PAS成核促Aβ聚集、经TLR4/NLRP3/CLIC1放大神经炎症（病理）→ 感染—炎症—Aβ/抗菌肽正反馈环。

## 机制落点（AChE–Aβ，多文献链，不只一篇动力学）

- **经典实验**：Inestrosa 1996 Neuron AChE使Aβ聚集26%→80%，PAS配体propidium抑制75%，活性位点抑制剂edrophonium无效 [27]
- **结构基序**：De Ferrari 2001 Biochemistry 4个潜在位点，Site I疏水序列35肽模拟完整AChE促聚集，Kd=184μM疏水主导 [29]；Inestrosa 2008 FEBS J综述PAS附近疏水环境及阻断 [30]
- **新基序**：N-端AChE 7-20 β-发夹为第二促聚集基序
- **动力学**：Atanasova 2020 对AChE–Aβ复合物 **1 μs（1000 ns）** MD，复合物稳定，除PAS外多处接触，**主要停留区344–361**，紧邻PAS但**不受双位点抑制剂位阻** [32]，意味着第二可利用界面
- **毒性增强**：Dinamarca 2010 Aβ-AChE复合物增强神经退行性变 [33]

## 由机制推出的三个可检验假设

| 编号 | 假设 | 验证方式 |
|---|---|---|
| H1 | 竞争PAS，减少AChE诱导成核 | 对接+MD比较结合自由能；propidium竞争；AChE酶活 |
| H2 | 直接结合Aβ，改变聚集路径与纤维形态 | ThT动力学、电镜/AFM、MD界面残基；参照LL-37-Aβ [10-12] |
| H3 | 膜水平作用，影响小胶质识别与炎症信号 | 脂膜模型MD+细胞炎症因子；参照CLIC1 [11] |

## 口径纪律

- 用“线索发现/假设提出/计算预测”，不用“证明/导致/因果”
- 数量差异一定说清哪一层（宿主 vs 微生物源、局部 vs 系统、总体活性 vs 具体肽、哪个阶段）
- “AD侧更多”是文献支持的预期方向，微生物源结论以本项目数据为准
- 动力学强调多文献链：Inestrosa 1996经典[27] → De Ferrari 2001基序[29] → Inestrosa 2008综述[30] → Atanasova 2020 MD[32]
- 感染关联区分病毒（HSV-1/HHV-6A/7）与细菌（P. gingivalis/LPS），并说明肠道起源
