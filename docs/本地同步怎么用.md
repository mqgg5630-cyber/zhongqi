# 本地怎么同步（只看这一页）

> 同步脚本**早就在仓库里**，不用再找、也不用改：根目录 7 个 `.ps1` + 4 个 `.cmd`，
> 完整说明在 `skills/git-sync/README.md`。

## 一、先进哪个文件夹

```
E:\0zhongqi\zhongqi          ← 就是这个（仓库根目录）
```

**不是** `E:\0zhongqi`（那是它的上一层，不是 git 仓库，脚本放那儿会报 “Not a git repository”）。
判断有没有进对：文件夹里能看到 `sync.ps1`、`sync.cmd`、`README.md` 和 `deliverable`、`中间版` 这些目录。

## 二、一键同步（双击就行）

| 想干什么 | 双击这个文件 | 或者命令行 |
|---|---|---|
| **拉最新**（最常用） | `sync.cmd` | `.\sync.ps1` |
| **把交付物下载到本机** | `download.cmd`（默认下载 final 集合） | `.\download.ps1 -Set final` |
| 体检（哪里不对劲先跑它） | `doctor.cmd` | `.\doctor.ps1` |
| 首次准备（换电脑才用） | `bootstrap.cmd` | `.\bootstrap.ps1` |
| 打包成 zip 交出去 | —— | `.\pack.ps1 -Set final` |

`.cmd` 只是 `.ps1` 的“双击外壳”（自动加 `-ExecutionPolicy Bypass`，避免策略拦截），行为完全一样、参数照样能传，
例如 `download.cmd -Set all` 或 `download.cmd -Set preview`。

> 为什么不用双击 `.ps1`：Windows 默认把 `.ps1` 当文本文件打开（记事本），双击不会运行；`.cmd` 才是双击即跑。

## 三、第一次用（只在没拉过脚本的旧克隆上需要）

如果文件夹里**看不到** `sync.ps1 / sync.cmd`，说明本地还没拉过带脚本的提交，先做一次裸 git（只需一次）：

```powershell
cd E:\0zhongqi\zhongqi
git fetch origin
git checkout arena/01a09d79-zhongqi
git pull
```

拉完就有 `sync.cmd` 了，以后**永远只双击 `sync.cmd`**。
（`bootstrap.cmd` 会自动做：放开执行策略 → 设 git 身份 → 切到工作分支 → 首拉。）

## 四、日常三条

```powershell
.\sync.cmd            # 1. 拉我（Agent）推的最新提交
.\download.cmd        # 2. 把 deliverable\ 中间版\ 中间版2\ 复制到本机下载目录
.\doctor.cmd          # 3. 出问题时先跑，一次看清 环境/分支/远端/未提交/stash
```

下载目录默认是仓库**上一级**的 `zhongqi_out\`（可在 `skills\git-sync\sync.config.json` 的 `download_dir` 改成绝对路径）。
`download.cmd` 只复制工作区里的文件——所以**先 sync，再 download**，否则拿到的是旧的。

## 五、出问题对照表

| 现象 | 处理 |
|---|---|
| 双击闪一下就没了 | 说明脚本没找到：确认文件在 `E:\0zhongqi\zhongqi` 根目录，窗口里会打印 `[exit code n]` |
| `running scripts is disabled` | 直接双击 `.cmd`（已带 Bypass）；或跑一次 `bootstrap.cmd` |
| 要密码 / 认证失败 | GitHub 不收密码：用 token、`gh auth login` 或 GitHub Desktop 登录一次 |
| 下载的文件是旧的 | 先 `sync.cmd`，再 `download.cmd` |
| 本地改动“消失” | 多半进了 stash：`git stash list` → `git stash pop` |
| 提示 `Updates were rejected` | 先 `sync.cmd`，再 `.\push.ps1` |
| 想看细节 / 更多故障 | `skills/git-sync/README.md` 第四节、第五节 |

## 六、那 11 个文件分别是什么

| 文件 | 作用 |
|---|---|
| `sync.ps1` / `sync.cmd` | 拉取工作分支最新（本地有改动会自动 stash） |
| `upload.ps1` | 传：把附件按扩展名归位到 `sources\` / `code\` / `results\` 后 commit + push |
| `push.ps1` | 单纯提交推送（拒绝推 `main`） |
| `download.ps1` / `download.cmd` | 按集合把目录镜像到本机（`final` / `docs` / `source` / `preview` / `all`） |
| `pack.ps1` | 打包成 `_export\日期_集合.zip` |
| `doctor.ps1` / `doctor.cmd` | 体检 |
| `bootstrap.ps1` / `bootstrap.cmd` | 首次准备 |
| `skills/git-sync/sync.config.json` | 唯一的配置：分支、远端、下载集合、下载目录、附件归位规则 |

改配置只动 `sync.config.json`，脚本不用动；`.ps1`/`.cmd` 里不许有中文（`python code/check_ps1.py` 会在提交前拦下来）。
