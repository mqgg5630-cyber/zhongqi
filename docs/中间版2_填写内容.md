# 论文题目
基于深度学习的阿尔茨海默症患者与健康人群肠道微生物组中抗菌肽的差异性研究

## 1. 论文研究主要内容及工作进度

!（一）选题背景与研究意义
!（二）国内外研究现状与本研究的切入点
然而，现有抗菌肽研究仍存在三方面不足。第一，训练数据与研究对象多为通用数据集与宿主来源序列，针对特定疾病人群、特别是神经系统疾病人群的工作较少，模型在目标人群中的适用性缺少检验；第二，研究多以"有或无抗菌肽"的二分类预测为终点，较少结合临床信息按疾病阶段分层，难以反映病程进展中的动态变化；第三，单一模型的预测结果受训练集偏倚影响较大，容易产生假阳性，需要多模型互证与表达层面的独立证据加以约束，而现有工作往往缺少这一层过滤。
基于上述现状，本研究以 AD 人群的公开宏基因组队列为对象，构建一条层层递进的分析链条：在序列层面构建微生物源短肽库并保留溯源信息，在预测层面采用多个模型独立预测并取共识结果，在统计与表达层面按认知阶段比较差异并以宏蛋白组证据二次去重，在功能层面从 AD 发病机制关联与抑菌活性两个方向开展初步验证。该设计针对已有研究在人群针对性、阶段分层与证据层次三方面的不足，构成本研究的切入点与特色。
!（三）研究目标
本研究的总体目标是：系统识别 AD 患者与健康人群肠道微生物组所编码的微生物源抗菌肽，阐明其在不同认知阶段的分布与组成差异，筛选出健康人群特有与各疾病阶段特有的候选抗菌肽，并初步建立这些候选抗菌肽与 AD 发病机制以及抑菌活性之间的联系，为后续深入的机制研究与潜在的干预线索提供依据。
具体目标包括：完成全队列宏基因组数据与微生物基因组参考集的处理与质量评估；建立覆盖全队列、来源可追溯的非冗余短肽库；获得经多模型共识判定、并经表达证据二次去重的候选抗菌肽集合；得到随病程变化的差异抗菌肽结果以及健康人群特有与各阶段特有的抗菌肽清单；形成候选抗菌肽与 AD 发病机制关联的分析结果；完成候选抗菌肽抑菌活性的初步实验验证；在此基础上完成学位论文并整理投稿论文。
!（四）主要研究内容
1. 宏基因组数据处理与微生物基因组参考集构建。完成全队列宏基因组数据的统一处理、质量评估与物种注释，获得高质量的微生物基因组参考集。参考集构建兼顾物种多样性与组装质量，尽量减少因不同样本组装质量差异带来的偏倚，为后续的序列预测与丰度比较提供统一、可比的分析基础。
2. 多模型共识预测候选抗菌肽。采用注意力机制模型、长短期记忆网络模型与语言模型三类结构对短肽库进行相互独立的预测，只有在三个模型上均被判为阳性的序列才纳入候选抗菌肽集合。该策略以模型间的相互验证降低单一模型带来的偏倚，在提高候选集合可信度的同时保留足够的序列规模，为后续差异分析提供输入。
3. 宏蛋白组表达证据二次去重与特有抗菌肽筛选。在序列去冗余的基础上引入宏蛋白组表达数据，剔除在蛋白层面缺少表达证据的序列，实现二次去重，降低"预测存在但实际不表达"的假阳性比例；在此基础上按组内共有与组间特有的比较策略，得到健康人群特有与各疾病阶段特有的抗菌肽清单，作为机制研究与实验验证的分析对象。
4. 候选抗菌肽抑菌实验验证。从特有肽清单中选取有代表性的候选抗菌肽进行人工合成，以大肠杆菌与金黄色葡萄球菌作为指示菌，先以纸片扩散法观察抑菌圈进行初筛，再以微量肉汤稀释法测定最低抑菌浓度，并设置阳性对照与阴性对照，从而获得候选抗菌肽具有抑菌活性的直接证据，为候选肽的生物学功能提供实验支持。
!（五）技术路线与实施要点
整体研究按四个层次推进，层次之间以统一的数据口径与可追溯的记录衔接。第一层是数据与序列层：宏基因组原始数据经过质量控制、去宿主、组装与物种注释形成微生物基因组参考集，再经小开放阅读框预测与去冗余形成微生物源短肽库。第二层是预测层：以三类深度学习模型独立预测短肽库，取一致阳性序列构成候选抗菌肽集合。第三层是统计与表达层：按认知阶段开展差异分析，并以宏蛋白组表达证据二次去重，得到健康人群特有与各阶段特有的抗菌肽。第四层是功能层：对特有抗菌肽开展机制关联分析与抑菌实验验证，最终汇总为学位论文与投稿论文的图表与结论。
!（六）工作进度与完成情况
1. 宏基因组数据处理与微生物基因组参考集构建：已完成，数据质量与样本覆盖情况已核查，参考集按物种多样性原则构建完毕。
2. 小开放阅读框预测与非冗余微生物源短肽库构建：已完成，短肽库覆盖全队列且来源可追溯。
3. 注意力机制模型、长短期记忆网络模型与语言模型三类模型的抗菌肽预测：已完成，已按三模型一致阳性的标准形成候选抗菌肽名单。
4. 其余各项（分阶段差异分析、宏蛋白组二次去重与特有抗菌肽筛选、机制关联分析、抑菌实验验证、结果整理与论文撰写）为中期之后的工作，实施方案与所需材料已确定。
从完成结构上看，研究内容中的宏基因组数据处理与微生物基因组参考集构建、小开放阅读框预测与微生物源短肽库构建两项已全部完成，三模型共识预测已形成候选抗菌肽名单，构成了课题的主体分析基础；分阶段差异分析、宏蛋白组去重与特有抗菌肽筛选正在开展，机制关联分析、抑菌实验验证与论文撰写安排在后续阶段进行。

## 4. 尚需完成的研究工作（包括内容、方案）

!（一）特有抗菌肽与 AD 发病机制的关联分析
内容：完成健康人群特有肽与各阶段特有肽的功能关联分析，判断候选抗菌肽是否可能参与 AD 相关的病理过程，形成关联结果清单与相应的图表，作为学位论文机制章节的主要内容。
!（二）候选抗菌肽的抑菌实验验证
方案：从健康人群特有与各阶段特有的候选肽中选取有代表性的序列进行人工合成，以大肠杆菌与金黄色葡萄球菌作为指示菌，先采用纸片扩散法观察抑菌圈进行初筛，再采用微量肉汤稀释法测定最低抑菌浓度；同时设置阳性对照（已知抗菌肽）与阴性对照（溶剂），每组设置重复，以保证结果的可判读性。实验统一在常规微生物实验室条件下开展，方法成熟、周期可控。
!（三）结果整理、论文撰写与投稿
方案：将候选抗菌肽名单、分阶段差异分析结果、健康人群特有与各阶段特有抗菌肽清单，以及机制关联分析与抑菌实验的结果汇总为完整的图表与结论体系，统一数据口径与图表规范；按学位论文写作规范完成学位论文，同时提炼方法学与分析框架方面的亮点整理为投稿论文。撰写过程中同步补充相关文献，使讨论部分与国内外研究现状相互衔接。
!（四）存在的问题与应对措施
1. 预测结果可能存在假阳性。应对：以多模型共识判定提高候选集合的可信度，再以宏蛋白组表达证据二次去重，最后通过抑菌实验对代表性候选肽进行验证，形成层层递进的证据链。
2. 分阶段差异分析与特有抗菌肽筛选尚在实施。应对：按既定流程推进，先完成差异比较与表达证据过滤，再冻结特有肽清单；后续机制关联分析与抑菌实验共用同一份清单，避免重复分析、控制工作量。
3. 机制关联分析的证据强度有限。应对：以分子对接与分子动力学模拟、文献比对为主，将研究定位为线索发现与假设提出，不夸大因果性结论。
